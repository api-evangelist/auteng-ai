AutEng provides an AI-native workspace for creating, editing, and sharing technical documentation. It supports Markdown, Mermaid diagrams, and KaTeX math, offering a collaborative platform with AI assistance for generating content, visualizations, and code examples. AutEng targets developers, engineers, and technical writers seeking modern, interactive documentation solutions.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for auteng-ai: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
